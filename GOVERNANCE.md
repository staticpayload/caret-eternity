# Caret Governance

## Project Status

Caret is currently in early development. Governance structures will evolve as the project matures.

## Leadership

Currently led by the core development team.

## Decision Making

Technical decisions are documented in Architecture Decision Records (ADRs) in the `adr/` directory.

Major decisions require:
- ADR documenting context and alternatives
- Review from core team
- Implementation plan

## Contribution Recognition

All contributors are credited in the release notes.

## License

MIT License - permissive for wide adoption and integration.

## Future Governance

As the project grows, we anticipate establishing:
- A technical steering committee
- Formal review processes
- Contributor tiers

For now, we maintain a lightweight, meritocratic approach.
